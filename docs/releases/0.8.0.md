## Slideshow

Open a photo, then **More options → Slideshow**. Choose 3, 5, 10, or 30 seconds per photo and start.

- Shows photos from the current timeline, Favorites, Archive, or album; videos are skipped.
- Pause/resume or advance to the next photo.
- Open **Slideshow options → Random photos** to toggle random order; the next photo will differ from the current one when possible.
- Choose **Exit slideshow**, or use Back, to return to the displayed photo.
- Waits for image loading before starting the interval, keeps the screen awake, and pauses when leaving the foreground. Failed images can be skipped automatically.
- An existing Google Cast connection follows the photos in nonFOSS. Physical TV playback has not been tested for this release.

## Downloads

- **FOSS:** no proprietary Google Cast SDK or Cast controls.
- **nonFOSS:** the same gallery plus Google Cast, requiring Google Play services for casting.

Both APKs are built and published by this GitHub Actions run, signed with the same certificate as previous releases. Install over your existing version without uninstalling. You can switch editions, but cannot install them side by side.

Android 8+. These remain development APKs using the existing debug signing certificate. The Actions workflow runs unit tests, Android Lint, the FOSS APK check, and certificate verification before publishing. Separate SHA256SUMS files are no longer attached; GitHub exposes each asset digest.

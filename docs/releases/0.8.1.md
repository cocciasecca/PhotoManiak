## Downloads

- **FOSS:** no proprietary Google Cast SDK or Cast controls.
- **nonFOSS:** the same gallery plus Google Cast; casting requires Google Play services.

Both APKs are built and published by GitHub Actions and signed with the existing certificate. Install over your current version without uninstalling. Editions can replace each other but cannot be installed side by side.

Android 8+. These remain development APKs using the existing debug signing certificate.

## Update notifications

- Get an in-app notice when a newer stable release is available for your edition.
- Check public GitHub releases automatically on startup, at most once a day. Disable automatic checks or use **Settings → Check for updates** at any time.
- Download the matching **FOSS** or **nonFOSS** APK through your browser. Installation remains manual.
- Dismiss a notice with **Later**; the same version is not automatically shown again.
- Update checks use a separate connection without kDrive credentials or photos. GitHub receives normal connection information, such as your IP address.

## Downloads

- **FOSS:** no proprietary Google Cast SDK or Cast controls.
- **nonFOSS:** the same gallery plus Google Cast; casting requires Google Play services.

Both APKs are built and published by GitHub Actions and signed with the existing certificate. Install over your current version without uninstalling. Editions can replace each other but cannot be installed side by side.

Android 8+. These remain development APKs using the existing debug signing certificate.

Versions before 0.8.3 do not include update notifications: download this update from GitHub manually. The new checker will notify you about subsequent releases.
